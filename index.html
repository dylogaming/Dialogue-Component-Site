🌿

Branching dialogues

Author conversations as numbered branches. Each player response can continue the scene, loop back, or end on the spot. Zelda-style continue buttons appear automatically when a choice is empty.

⚖️

Conditions

Gate responses on player stats. Check Gold ≥ 3 or Evidence ≥ 1, then subtract on success. Failed choices can stay shown, grey out, or vanish.

💾

Save system

One save ref captures every actor's transform, current branch, and player conditions, restored exactly on load. Drops into your own save flow too.

📊

CSV data tables

Write whole conversations in Excel and import them straight into a data table. Branches, choices, audio, and animations resolve by name. Export any table back out for round-trip editing.

Conditions (("Energy", 1),("Money", 5))
🎬

Moving actor & camera

Spline-driven rails, doors, elevators, and helicopter fly-bys. The camera tracker keeps framing consistent across any character.

🎨

Rich text & icons

Inline color and style tags, speech-bubble and map icons, custom fonts, and true character-by-character typing at any text length.

🎥

Level sequences

Fire off level sequences mid-conversation with fade in/out and per-shot settings for fully directed story beats.

🖱️

An editor that lives in your browser

The Editor Utility keeps every variable visible while you work: preview camera angles, test conditions, and tweak branches with instant sync back to the Details panel. Built for fast iteration, not menu-diving.
